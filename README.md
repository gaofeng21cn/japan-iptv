# 日本电视精选订阅

这是给家庭网络和 APTV 用的日本电视播放列表。订阅入口固定是：

```text
https://raw.githubusercontent.com/gaofeng21cn/japan-iptv/main/playlist.m3u
```

在 APTV 里添加为远程 M3U 订阅即可。以后列表更新，刷新同一个订阅，不需要重新添加，也不需要更换地址。

## 维护方式

仓库会定期或不定期检查上游变化和线路可用性，优先保证常用地上波频道稳定可用。正式列表只包含已经确认的地址；候选和测试结果不进入订阅。

更新后的 `playlist.m3u` 会自动发布到 `main` 分支。APTV 刷新订阅后即可使用最新版本。

## 说明

这里是公开的播放列表仓库，只保存公开频道地址，不包含家庭网络配置、机场订阅、节点信息、Cookie 或代理凭据。视频播放仍由各上游服务器直接提供给播放器。
